# resources/

Place your CV/Resume PDF here:

- **Rename your file to `cv.pdf`** so the sidebar "Resume / CV" link works out of the box.
  - Or update the `href` in `index.html` to match your filename:
    ```html
    <a href="resources/YOUR_FILENAME.pdf" target="_blank">
    ```

You can also store other downloadable resources here (e.g. thesis, slides).
