# images/

Place your images here, organized into subfolders:

## Folder layout

```
images/
├── photo.jpg               ← Your profile/headshot photo
├── projects/               ← Project thumbnail images (300×180px recommended)
│   ├── project1.jpg
│   └── project2.jpg
├── publications/           ← Paper figure / teaser images (200×140px recommended)
│   ├── paper1.jpg
│   └── paper2.jpg
└── misc/                   ← Award ceremony / event photos (any size, 4:3 crop)
    ├── award1.jpg
    └── award2.jpg
```

## How to use

See the **README.md** in the root folder for step-by-step instructions on
linking each image into `index.html`.

## Recommended sizes

| Use              | Recommended size    |
|------------------|---------------------|
| Profile photo    | 300×300px (square)  |
| Project image    | 360×220px           |
| Publication thumb| 240×170px           |
| Misc / award     | any, 4:3 ratio      |
